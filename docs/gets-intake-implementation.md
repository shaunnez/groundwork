## Access checkpoint

The current [GETS terms](https://www.gets.govt.nz/GetsTermsAndConditions.htm), clause 3.2(i)(e), restrict use of software or other methods to monitor, copy, collect or index GETS content. Clause 3.2(ii) covers account confidentiality, and 3.5 has limits on material posted by users and republication. A public page or RSS link alone is not an approved Groundwork collection route. The only official open dataset located so far is [MBIE's quarterly award data](https://www.mbie.govt.nz/cross-government-functions/new-zealand-government-procurement-and-property/open-data), which is useful for award context but is not a current/future tender feed.

`GROUNDWORK_GETS_APPROVAL_FILE` remains unset. The hosted pilot instead has `GROUNDWORK_GETS_TEST_ACCOUNT_ID` and `GROUNDWORK_GETS_TEST_UNTIL` set for Shaun's explicit test instruction. The latter expires 6 October 2026 22:27 UTC; the worker rechecks it on each step. This setting records operator authority only. Once a GETS/MBIE arrangement is available, record its actual route, scope, rate, storage, derived-report, recipient and retention conditions separately, then replace the test setting. Do not call the existing test permission from GETS.
